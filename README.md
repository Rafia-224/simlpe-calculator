# simlpe-calculator
simlpe calculator  built with python
Simple Calculator

A simple and beginner-friendly calculator program that performs basic arithmetic operations.

Features
Addition
Subtraction
Multiplication
Division
Simple and easy-to-use interface
Handles basic input errors
Operations
Operation	Description
+	Addition
-	Subtraction
*	Multiplication
/	Division
Example
Enter first number: 10
Enter operator: +
Enter second number: 5

Result: 15
How to Run
Clone or download the project.
Open the project in your preferred code editor.
Run the calculator program.
Enter two numbers and select an arithmetic operation.
The result will be displayed on the screen.
Error Handling

The calculator handles invalid operations and prevents division by zero.

Purpose

This project is created for beginners to practice basic programming concepts such as:

Variables
User input
Arithmetic operators
Conditional statements
Basic error handling
